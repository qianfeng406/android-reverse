# D2 首版验收记录

## 范围

D2 建立块观察图，以可选原子规则提出共享回跳分发结构候选，并输出下一阶段的条件状态探针计划。模型适配器可选运行，只保存经引用与函数范围检查的只读提案；实际结构判断仍由规则产物给出。

## 可复现检查

在 `reverce` 目录运行 [使用说明](USAGE.md) 的 `init → static → import-legacy → discover → stage --from-stage 2` 命令，再运行：

```powershell
python -m unittest discover -s deobfuscation-tool -p 'test_*.py' -v
```

17 项测试通过。`lesson_score` 的规则输出首位候选为回跳块 `0x18F8`、状态槽 `sp+4`；自动探针来源为 `0x1760`、`0x17BC`、`0x17E0`、`0x188C`。测试没有向发现器预填这些地址。另有普通高频循环和其他模块同偏移夹具；关闭状态证据规则时结果为 `unresolved`。旧 trace 的相邻块没有被标成直接 CFG 边，每条观察转移保留事件引用。

Codex 适配器的命令、输出、失败和引用校验由模拟子进程测试。一次本机 `--use-model` 实测在默认 120 秒超时；将超时放宽至 240 秒并缩短输入后，在线模型成功返回 `0x18F8–0x18FC`、`sp+4` 的结构提案，引用校验通过。在线模型响应不作为回归测试的通过条件。D2 对真实设备采集文件的离线 `discover` 运行成功，与旧日志得到相同的首位回跳块、状态槽和四个探针。

## 当前边界

- 识别器主要支持共享回跳与栈状态槽比较链；规则是候选证据，不能证明全部后继。
- 状态别名只处理同块读写线索，不进行跨块精确数据流或符号执行。分层、多局部分发、间接地址计算与混合块需要后续策略。
- 目前 `side_effect` 仅标记分发区域内的 `BL/BLR/SVC`，不是完整副作用审计；D5 前不能据此绕过指令。
- `probe_plan` 给出位置和待记录字段，尚未实际部署 Frida 定点探针；这属于 D3。
- 模型可用 `rule:<规则名>` 选择可选证据规则；不可关闭五条核心规则，亦不直接给结构候选盖章。在线模型本次返回的检查建议为自然语言，因此本次运行使用默认组合。
